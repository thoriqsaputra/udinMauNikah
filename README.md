# Deskripsi Program
Hailday adalah sebuah aplikasi simulasi pengelolaan ladang berbasis Antarmuka Pengguna Grafis (APG) yang dikembangkan menggunakan bahasa pemrograman Java. Aplikasi ini dirancang untuk memfasilitasi penanaman tanaman dan pemeliharaan hewan pada petak ladang yang disusun dalam grid 4x5 dan 5x6. Setiap petak dapat ditempati oleh tanaman atau hewan dan dapat diberi item untuk meningkatkan hasil atau melindungi dari serangan beruang. Pengguna dapat mengelola ladang mereka, membeli dan menjual produk di toko.
